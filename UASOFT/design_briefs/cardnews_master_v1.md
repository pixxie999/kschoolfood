# 📄 UASOFT Official Card News Master Template Design Brief (v1.0)

## 🎯 Project Goal: 정보 전달력을 극대화하는 신뢰 기반의 비주얼 시스템 구축
*   **핵심 목적:** 40~50대 직장인/자영업자의 '효율적 학습' 경험을 제공하며, UASOFT를 전문적인 지식 출처로 포지셔닝.
*   **톤앤매너:** Professional, Clear, Trustworthy (전문적이되, 어렵지 않고 믿음직함).

## 🎨 Visual System Guidelines

### 1. Color Palette (신뢰와 명료성)
| 역할 | 색상명 | HEX Code | 사용 가이드라인 |
| :--- | :--- | :--- | :--- |
| **Primary** | Deep Navy | `#1A237E` | 배경, 메인 타이틀. 신뢰감 부여의 주색. (가장 많이 쓰이는 색) |
| **Secondary** | Clean Sky | `#42A5F5` | CTA 버튼, 핵심 강조 키워드/숫자. 명확한 액션 유도 및 포커스 포인트. |
| **Accent** | Warm Gray | `#EFEFF3` | 내용 분리 영역 배경. 시각적 여백 확보. |
| **Base** | White / Dark Grey | `#FFFFFF` / `#333333` | 기본 바탕색, 본문 텍스트.

### 2. Typography (가독성 최우선)
*   **서체:** Pretendard (프리텐다드) - 웹 환경에 최적화된 가독성 높은 산세리프.
*   **계층 구조:** H1(32-48pt, Bold, Navy) > H2(20-26pt, SemiBold) > Body(14-18pt, Regular, #333333).

### 3. Layout Rules (미니멀리즘 & 시선 유도)
*   **여백:** 모든 요소는 최소한의 여백을 확보하여 답답함을 제거한다.
*   **정보 구조화:** '제목 → 문제 제기(Pain Point) → 해결책 원리(개념도) → 적용 방법(Case Study)' 순서로 정보를 배치하는 것을 표준으로 한다.

## 🧩 Master Template Sequence (총 6컷 기준)

| No. | 역할 | 목표 및 내용 구성 | 디자인 액션 |
| :--- | :--- | :--- | :--- |
| **1/6** | **[Hook] 문제 제기** | 독자의 시선을 사로잡는 강력한 질문이나 통계 제시. (예: "아직도 수기로 이 작업을 처리하시나요?") | Deep Navy 배경 + 흰색 텍스트 조합으로 임팩트 최대화. H1 카피가 전면에 배치되어야 함. |
| **2/6** | **[Pain Point] 공감 형성** | 타겟이 느끼는 구체적인 어려움(지루한 과정, 시간 낭비 등)을 명확히 지적. | Warm Gray 배경에 ❌ 아이콘과 함께 문제점을 나열. 감정적으로 연결되는 문구 사용 권장. |
| **3/6** | **[Concept] 해결 원리 제시** | 이 문제를 풀 수 있는 '새로운 개념'이나 '원리'를 간결하게 소개. (기술 용어는 비유와 흐름도로 설명.) | 클린 스카이 색상으로 강조된 핵심 다이어그램 사용. 복잡한 설명은 피하고, 과정(Flow)에 집중. |
| **4/6** | **[Detail 1] 방법론 A (근거)** | 개념을 구체화하는 첫 번째 방법을 데이터 기반으로 제시. | 제목(H2), 본문(Body), 그리고 반드시 간결한 그래프 또는 통계 시각 자료를 포함한다. |
| **5/6** | **[Detail 2] 방법론 B (적용 사례)** | 실제 사용자가 어떻게 적용할 수 있는지 'Before & After' 형태로 제시. | 구체적인 Use Case 예시를 통해 직관성을 높인다. (ex: "수작업 A → 자동화 B"). |
| **6/6** | **[CTA] 요약 및 행동 유도** | 핵심 메시지 3가지 요약 + 다음 액션(공식 블로그 방문, 자료 다운로드 등) 안내. | Deep Navy 또는 화이트 배경에 '클린 스카이' 버튼을 중앙에 배치하여 명확하게 클릭하도록 유도. |
